# Pattern Clash

A real-time lane-battle strategy game that teaches data structures and algorithms in C++, problem by problem, across the full Striver A2Z DSA sheet (455 rows, 18 arenas).

Win a battle by actually solving the problem:

- **Recognise:** deploy the right pattern card (Two Pointers, Sliding Window, Monotonic Stack, BFS, DP…) from the statement and constraints.
- **Build:** write the solution one component at a time (state, init, loop, invariant, answer, edge guards), then whole from memory, judged by a real in-browser C++ compiler.
- **Prove:** state and derive time and space complexity; break the towers by passing sample and hidden tests.
- **Explain:** give a 60-second interview explanation and grade it against a model answer.
- **Adapt:** survive overtime follow-up waves where the interviewer changes the constraints.

Spaced-repetition chests, pattern-card levels, a trophy road through the sheet, ladder and OA modes. Playable on desktop and phone as an installable PWA.

Status: early development. All problem statements and explanations are original; the game uses no third-party game art, names or sounds.

## Stack

Next.js · React · TypeScript · PixiJS · CodeMirror · clang compiled to WebAssembly · Postgres (Neon) · Vercel
